🔥 今日头条 · 三条主线

① 新模型 · 免费档可用 Anthropic 发布 Claude Haiku 5.5：免费版 Claude 应用就能用，$0.10 / $0.50
本期唯一一条「旗舰级新模型直接对免费用户开放」——不是免费 API，而是把 Haiku 级模型放进了免费版 Claude 应用。 当地时间 10/7，Anthropic 发布 Claude Haiku 5.5，是 Claude 5.5 家族的第三款（前有 Opus 5.5 与 Sonnet 5.5）。
💵 定价与规格
输入 $0.10 / 百万、输出 $0.50 / 百万（prompt ≤100K）；>100K 升到 $0.50 / $2.50。
比 Haiku 4.5 便宜约 75%，官方称「迄今最快的小模型」。
1M 上下文 / 128K 最大输出；Haiku 级首次支持 effort 档（自适应思考）；知识截止 2026 年 6 月。
🎁 免费入口在哪（关键）
官方口径：即日起在「所有平台」提供，包括免费版 Claude 应用（含网页与 App）。
API 侧同步上架：OpenRouter anthropic/claude-haiku-5.5（1M、$0.10/$0.50）、OpenCode Zen claude-haiku-5-5；另可在 AWS Bedrock / Google Cloud / Microsoft Foundry 调用。
⚠️ 免费只发生在 Claude 应用这一层，API 侧仍按量计费。
📈 能力定位
OSWorld 2.1（电脑操作）超 OpenAI GPT-6 Luna；可作为 Opus 5.5 / Sonnet 5.5 的子智能体用于编码。
面向：分类、摘要、抽取、实时客服、语音 agent、应用内助手——典型「高频、低成本」工作。
Anthropic 首个内置「窄域高危网络安全请求」防护的 Haiku；Max / Team 订阅另赠每月 API 额度。
⚠️ 迁移注意
为 Haiku 4.5 写的代码在 5.5 上会 break：手动 extended thinking（budget_tokens）返回 400。
adaptive thinking 默认开启，响应可能以 thinking 块开头；相同文本会计入更多 token。
一句话：Claude 5.5 三档（Opus → Sonnet → Haiku）到齐，「小模型免费档」这一格由 Haiku 补上。
为什么 Haiku 5.5 要写进「免费日报」近一个月的主线是「免费池收缩、低价档变便宜」。Haiku 5.5 把 Haiku 级价格压到 $0.10/$0.50，同时把 Haiku 级放进免费 Claude 应用——这是「便宜档」第一次直接摸到免费用户。
对个人来说，它给了你一条无需任何 key、无需绑卡的「先进模型试用入口」，值得今天就摸一遍。
同一周的另一条：Anthropic 创业扶持10/6 SF Tech Week 期间，Anthropic 推出扶持计划：成立 5 年内或近两年获融资的初创，可免费用 Claude Team 一年（最多 5 席）+ $1000 API 额度。
读法：模型竞争正从「比参数」转向「比开发者忠诚度」——如果你的项目符合条件，这是一条被低估的免费额度。
② 新模型 · 开源路线 Mistral 发布 Large 4：1.05T MoE / 49B 激活 / 1M 上下文，月底开源权重
欧洲开源路线的旗舰：把万亿级 MoE 的激活压到 49B——意味着「前沿级能力」有机会以「可自托管」的形态落到免费侧。 当地时间 10/6，Mistral 发布 Mistral Large 4（内部代号 ML4），公开预览状态。
🧬 规格
1.05T 总参数 / 49B 激活（约 4.7%）、1.6B 视觉编码器、1M 上下文；文本 + 图像输入。
原生支持 160+ 语言（含全部欧盟官方语言）；支持函数调用、结构化输出、文档问答、批处理与 Agents / Conversations API。
在自有欧洲数据中心的 3,800 块 NVIDIA Grace Blackwell 上训练。
💵 定价
标准 $1.36 / $4.18 per M（缓存输入 $0.14）；预览期打折 $0.68 / $2.09、缓存 $0.07。
OpenRouter 上架 mistralai/mistral-large-4-0（512K、$0.68 / $2.09），OpenCode Zen 上架 mistral-large-4（均付费）。
⚠️ 目前没有任何免费 API 入口。
📈 跑分
DeepSWE v1.1 61.7% / SWE-Atlas-QnA 59.4% / Terminal-Bench 4 28.3% / AutomationBench 59.9%。
Cybench 网络安全 93%、AA Cyber Index 82%；Surge AI 编码人工评测 3.74 / 5（对比 Opus 5 的 4.22、GLM-5.3 的 3.6）。
强项：编码 agent、长终端流程、安全、金融与法律文档。
🎁 为什么它对「免费」有意义
官方承诺月底发布权重（许可证待公布）。参照 Mistral Large 3 是 Apache-2.0、长期出现在各类免费托管与自建清单里——Large 4 若沿用开放许可，月底就会多一条「可自托管的前沿级」选项。
建议：现在把它记进候选清单，10 月底回来核一次许可证。
同一周两条「万亿 MoE」对照本期两件大事都指向同一技术路线：Mistral Large 4（1.05T / 49B 激活）与免费侧的 Ling 3.1 Flash（560B / 25B 激活）。
「总参数越堆越大、激活参数越压越小」已是 2026 下半年的默认打法——这直接决定了推理成本，也正是「便宜模型越来越强」的底层原因。
